# Project Operating Rules — Smart Cafeteria Waste Reduction System

## 1. Complete Project Autonomy & Isolation
- This project is **100% independent and autonomous**.
- NEVER import, copy, reference, or cross-link code, assets, data, or configuration from any other project or workspace (e.g. vividh-edu, VividhOS, Roop, etc.).
- All dependencies, models, and databases must be self-contained within this repository.
- Git remotes must strictly point to this project's dedicated repository (`vividhedu-hash/Smart-School-cafeteria-tracker.git`).

## 2. Automatic Git Publishing on Task Completion
- At the end of every chat turn or completed task that modifies files:
  1. Run the test suite to ensure no regressions: `PYTHONPATH=.:src:dashboard .venv/bin/pytest -q`.
  2. Stage modified and new safe files: `git add <files>`.
  3. Commit with a clear semantic message: `git commit -m "..."`.
  4. Publish changes to GitHub: `git push origin main`.
